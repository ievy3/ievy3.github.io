PATCH GUIDE

패치 적용 가이드

각 프로젝트의 지원 원본과 주의사항이 우선입니다. 아래 내용은 Noctil Patchworks 패치를 처음 적용할 때 공통으로 확인할 기본 순서입니다.

BASIC FLOW

기본 적용 순서

프로젝트 페이지의 최신 버전과 지원 원본을 먼저 확인한 뒤 진행하세요.

지원 원본 확인

게임명만 같아도 지역·제품 코드·PSN/UMD 판본에 따라 패치 대상이 다를 수 있습니다. 각 프로젝트의 ‘지원 원본’을 기준으로 준비합니다.

깨끗한 원본 준비

이전 한글 패치가 적용되지 않은 원본을 사용합니다. Noctil Patchworks는 원본 ROM·ISO나 패치 적용 완료 이미지를 제공하지 않습니다.

최신 패치 다운로드

프로젝트 페이지의 ‘패치 다운로드’ 버튼에서 최신 공개본을 받습니다. 이전 버전이 필요한 경우 해당 프로젝트의 패치 이력을 확인합니다.

패처 실행 및 결과 확인

배포 파일의 안내에 따라 패처를 실행합니다. 패치가 끝나면 새로 생성된 결과물을 사용하며, 기존 패치본 위에 새 버전을 덧씌우지 않습니다.

BEFORE YOU PLAY

실행 전 확인

ISO 형식 CHD·CSO 등 압축 형식은 프로젝트에 따라 직접 입력할 수 없습니다. 안내에 별도 언급이 있으면 ISO로 변환한 뒤 적용하세요.
PPSSPP 패치 적용 후 새 게임 이미지로 실행합니다. 문제가 생기면 사용 중인 PPSSPP 버전과 발생 위치를 함께 기록해 주세요.
PSP / PS Vita 실기 호환 여부는 프로젝트별 검증 범위가 다릅니다. 대문 카드와 프로젝트 페이지의 검증 상태를 먼저 확인하세요.
세이브·인스톨 데이터 기존 데이터와의 호환성이나 주의사항이 있는 작품은 프로젝트 페이지 안내가 우선입니다. 이상이 있으면 새 데이터로 재현 여부를 확인해 주세요.

REPORT A PROBLEM

문제가 발생했나요?

패치 버전, 실행 환경, 발생 장소와 상황, 재현 방법, 가능하면 스크린샷을 함께 남겨 주면 확인이 빨라집니다.

원본 게임 파일은 첨부하지 마세요. 프로젝트별 오류 제보 링크가 있으면 해당 링크를 우선 사용해 주세요.
