패치 요청

번역 패치가 있었으면 하는 게임을 알려 주세요. 이미 올라온 게임이면 새로 쓰지 말고 👍 응원을 눌러 주세요.

요청 남기기 ↗
  • 요청과 응원은 GitHub 계정이 있으면 누구나 남길 수 있습니다.
  • 게임 ROM·ISO 파일이나 다운로드 링크는 올리지 마세요.
  • 다른 제작자에게 이미 요청한 패치는 중복으로 요청하지 마세요. 작업이 겹칠 수 있습니다.
  • 요청이 많다고 반드시 작업하는 것은 아니며, 작업 여부와 순서는 제작자가 정합니다.
