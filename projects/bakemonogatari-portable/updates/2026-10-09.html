BASE VERSION

기준판과 원본 확인

  • 일본어판을 기준으로 작업하며, 영어판과 파일 단위로 비교했습니다. 공개된 영어 번역 프로젝트의 기술 자료도 참고합니다.
  • 수정 없이 다시 만든 게임 이미지가 원본과 완전히 같다는 것을 확인했습니다.
  • PPSSPP에서 원본 타이틀·메뉴·새 게임·튜토리얼 진행을 확인했습니다.

SCREEN LIMITS

화면별 표시 한도

  • 하단 대사창: 한 줄 32자에서 잘리고, 16자씩 두 줄로 나누면 완전히 표시됩니다.
  • 메뉴 설명은 3줄, 안내창은 4줄까지 여유 있게 표시됩니다.
  • 도움말은 한 줄이 길면 셋째 줄 뒤쪽이 잘려 줄바꿈 기준이 필요합니다.
  • 목록 항목은 22자까지 표시되고 넘치면 말줄임표로 바뀝니다.
  • 실제 게임 화면 18곳에서 원문과 표시 위치를 연결했습니다.

TRANSLATION POLICY

확정한 번역 방침

  • 기존 한국어판에서 확인되는 표기를 우선합니다.
  • 원문의 호칭과 경어 차이를 살립니다.
  • 말장난은 한국어로 다시 만들어 옮깁니다.
  • 口撃은 ‘말싸움’, 語録은 ‘대사 덱’으로 옮깁니다.
  • 글꼴은 Noto Sans CJK KR Regular를 사용합니다.
  • 용어 107개와 인물 관계 18건을 정리했습니다.
