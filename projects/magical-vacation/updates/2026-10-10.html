IMAGES

그림 10장 추가 한글화

  • 영어 팬 번역판이 바꾼 그림을 모두 대조해, 남아 있던 일본어 그림을 추가로 한글화했습니다.
  • 추가한 그림: 통신 안내 3종(통신 확인 중·기다리세요·통신 오류), 우정, MISS, 상태 이상 5종(마비·저림·독·석화·잠)
  • 이로써 한글화한 그림은 모두 27장입니다. MISS를 제외한 9장은 아직 실제 화면에서 보지 못했습니다.

SAVE

세이브 호환성

  • 이름이 세이브에 글자 번호로 저장되기 때문에, 앞으로 업데이트에서도 한글 글자 번호가 바뀌지 않도록 고정했습니다.
  • 다른 버전 사이에서 세이브를 불러오는 시험은 아직 하지 않았습니다.

RELEASE

v0.9.0 배포 준비

  • 기존 Noctil Patchworks 패처와 같은 방식의 Windows 오프라인 패처(EXE)를 만들었습니다. 별도 프로그램 설치 없이 원본 롬에 바로 적용됩니다.
  • 원본 롬 확인 → 패치 적용 → 결과 확인까지 자동으로 검사하며, 원본 파일은 건드리지 않습니다.
  • 직접 적용용 BPS·xdelta 패치도 함께 제공합니다.
  • 한글 글꼴 Galmuri(SIL Open Font License 1.1)의 라이선스 고지를 함께 넣었습니다.
  • 패처는 코드 서명이 없어 Windows SmartScreen 경고가 나타날 수 있습니다.
