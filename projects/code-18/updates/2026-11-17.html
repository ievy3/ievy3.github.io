시험 플레이 제보 처리

사용자 시험 플레이에서 나온 옵션 화면 글자 문제를 고쳤습니다.

FIXES
19→0곳옵션 글자 잘림
3행음성 강조 값 추가
7장바뀐 화면 통과

FIXES

수정

  • 메뉴 「빠른 불러오기」를 「빠른 로드」로 바꿨습니다(□ 메뉴의 「로드」 칸이 7바이트라서).
  • 옵션 제목 한글의 위·아래가 잘려 보이던 문제는, 제목 그림판이 높이 16행이라 한글 받침을 잘라 내던 것이 원인이었습니다. 창 높이 상수를 늘리고 같은 문제가 있던 다른 화면(CLEAR LIST 등) 4군데를 고쳐, 잘림이 19곳에서 0곳이 됐습니다.
  • 옵션 「음성 강조」 값 小·中·大가 네모(□)로 보이던 것은 실행 파일의 글자 목록이 4바이트 미만 문자열을 빼고 있었기 때문이라, 「약·중·강」 3행을 추가해 고쳤습니다.
  • 바뀐 화면 7장을 확인해 모두 통과했습니다.
