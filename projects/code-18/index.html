한글화 범위

  • 대사·선택지·이름표 24,776행, 메뉴·옵션·시스템 문구 188행, 엔딩 이름 목록 12행
  • 오프닝 영상의 화면 글자(로고 밑 작은 글씨, 스태프, 히로인 이름 카드와 성우 줄) 14곳
  • 그림 14장: XMB 배경(PIC1), 타이틀 로고, 불러오기 그림, 조작 설명 화면, 앨범 인물 이름 3장, 앨범 배경 이름판 6장, 조작 단추 그림
  • 번역은 용어·말투 정본을 만들어 외부 검수를 거쳤습니다.
  • 글꼴: 게임 Spoqa Han Sans Neo, 조작 설명 그림 Noto Sans KR, 앨범 이름·이름판 등 작은 그림 글씨 갈무리(Galmuri)

일부러 그대로 둔 것 · 알려진 한계

배경 그림 속 일본어(간판·포스터·칠판·빛 글씨 등 14장), 앨범 CG 축소판 2장, 오프닝 이외의 영상 4개(노래뿐, 화면 글자 없음), 영문 표기(TEXTLOG, STICK, SELECT 등)는 그대로입니다. 오프닝 영상의 히로인 이름 카드 일부(타테카와 타마키 카드의 작은 잔상 조각, 성우 줄 2곳의 작은 글자)를 다듬지 못했습니다. 프롤로그 일부 장면 전환에서 대사 창이 8~9초 비는 것, 「불러 본다」 선택지에서 가끔 선택 띠가 없고 ○ 단추가 듣지 않는 것은 일본어 원본에서도 같은 동작입니다(START를 누르면 풀릴 수 있음). 확인 창 일부에서 글자가 가장자리에 닿고 대사 창 글자가 세로로 약간 눌려 보인다는 의견이 있었으며, 게임 업데이트 알림(XMB)은 동작하지 않을 수 있습니다.

확인 범위

PPSSPP에서 화면을 확인했고, 제작자가 PSP 실기에서 게임 진행 약 20%와 오프닝 재생을 확인했습니다. 일본어판에서 만든 세이브를 그대로 불러와 이어 할 수 있는 것을 PPSSPP에서 설치 있음·없음 모두 확인했습니다. 엔딩, 앨범에서 아직 열리지 않은 인물 칸, 「불러오는 중」 그림, 조작 단추 그림(STICK) 화면, 설치 중·설치 실패 메시지, 저장 중·불러오는 중 메시지, 줄 나눔이 바뀐 대사 5행, 실기의 시스템 저장 화면 제목은 직접 보지 못했고, 처음부터 끝까지의 전체 시험 플레이는 하지 않았습니다.

원본 해시가 다르면 패처가 적용을 거부합니다. CSO·CHD는 먼저 ISO로 바꿔 주세요. 일본어판에서 타이틀 메뉴의 GAME DATA INSTALL(설치)을 했다면 메모리스틱의 PSP/SAVEDATA/ULJM05936INSDIR 폴더(약 446MB)를 지운 뒤 시작하세요(세이브 폴더는 지우지 마세요). 패치한 ISO로 다시 설치하는 것은 시험하지 않았으니 설치하지 않고 쓰기를 권합니다. 일본어판 세이브는 그대로 불러올 수 있고, 한글판 이전에 만든 세이브는 한 번 다시 저장하면 제목이 한글로 바뀝니다. PPSSPP에서는 텍스처 업스케일을 끄고 필터링을 「근접」으로 두세요. 세이브는 꼭 백업해 주세요.
