한글화 범위

  • 대사·선택지·메뉴 등 번역 22,914행(153묶음)과 실행 파일 안 문구 186행, 엔딩 이름 12행
  • 그림: 타이틀 로고, 앨범 인물 이름·배경 이름판, 조작 설명 화면, 단추 그림 등 사용자 승인 그림 13장과 일본어 그림 15장
  • 글꼴: 한글 2,350자를 Noto Sans KR로 새로 그렸습니다.

알려진 문제(수정 중)

옵션 화면의 제목 글자가 위아래로 잘려 보이는 문제, 옵션 「음성 강조」 값이 네모(□)로 보이는 문제를 고치는 중입니다. 옛 세이브의 제목은 일본어로 남습니다. 클릭 대기 표지가 없고, 한 쪽이 4줄로 나오는 곳이 있으며, 덮어쓰기 확인 창에서 글자가 닿는 곳과 「예」-「/」 간격 문제, 바로가기 목록에 「? ? ?」가 나오는 곳이 남아 있습니다. 배경 그림 속 글씨는 일부러 그대로 둡니다.

확인 범위

PPSSPP에서 화면 92장을 점검했고, 바뀐 화면 13장을 다시 확인했습니다. 직접 시험 플레이가 진행 중이며, 불러오는 그림, 단추 화면, 이름판은 아직 확인하지 못했습니다. PSP 실기에서는 확인하지 않았습니다.
