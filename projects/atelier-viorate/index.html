작업 상세 정보한글화 범위 · 원문 유지 · 확인 범위

한글화 범위

  • 실행 파일 안 대사·메뉴·아이템·조합·설명·도움말 문자열 13,331개, 시스템 문구 35개, 코드가 직접 가리키는 낱말 4개
  • 그림 189장: 타이틀 로고, 메뉴·도움말 제목, 대사창 이름표, 조합 카드, 아이템 이름 판 등과 저장 썸네일 로고
  • 게임 글꼴: 한글 2,350자를 Galmuri11(12px)로 새로 그렸습니다. 그림 글자: Galmuri 계열, Noto Sans KR, Black Han Sans, Jua, Silver font

알아 두실 점

타이틀 메뉴의 「데이터 설치」를 쓰면 게임이 설치된 일본어 원본 그림을 읽어 타이틀 로고·메뉴 제목 등이 일본어로 돌아가므로 사용하지 마세요. 설치 데이터는 원본 그대로입니다.

확인 범위

PPSSPP에서 확인했고, 실기 PSP-1000에서도 동작을 확인했습니다. 첫 전투 밖의 전투, 상점, 의뢰 게시판, 마을 이동·지도, 대부분의 이벤트 장면과 엔딩은 직접 보지 못했고, 일본어판 세이브 이어하기도 확인하지 못했습니다. 처음부터 끝까지의 전체 시험 플레이는 하지 않았습니다.
