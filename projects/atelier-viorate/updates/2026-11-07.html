구조 파악과
첫 한글 표시

게임 데이터 구조와 글꼴을 찾아내 처음으로 한글 대사를 화면에 띄웠습니다.

START
13,631행문자열 추출
709개묶음 항목 왕복 일치
2,350자한글 칸 배정

FOUND

알아낸 것

  • 데이터는 압축 묶음 2개와 실행 파일이며, 실행 파일은 암호화돼 있어 에뮬레이터로 복호화본을 얻었습니다.
  • 대사·메뉴 문자열이 실행 파일 안 일본어(Shift-JIS) 뭉치와 고정 주소 표에 있다는 것을 확인했습니다. 문자열 13,631행을 뽑아 다시 넣어도 일치하는 것을 검증했습니다.
  • 압축 해제·압축 도구를 만들어 묶음 항목 709개가 왕복해도 같은 것을 확인했습니다.
  • 글꼴은 시스템 글꼴이 아니라 실행 파일 안의 정적 자료이고, 글자 하나가 16×16 4비트 그림(3,384자)이라는 것을 찾았습니다.

MADE

만든 것

  • 한자 칸 2,350개를 한글 음절에 배정하고 글꼴을 바꾸는 도구를 만들어, 에뮬레이터에서 첫 한글 대사를 표시했습니다.
  • 반각 공백이 뒤 한 글자를 삼키는 규칙을 찾아 전각 공백으로 보내도록 정했습니다.
  • 시험 표 20행을 화면에서 확인했습니다.
