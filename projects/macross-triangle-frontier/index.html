한글화 범위

  • 대사·학원 이벤트·미션 브리핑·메뉴·설명·스태프롤 약 48,300행
  • 실행 파일 속 문구 약 2,875행
  • 글자가 든 그림 1,123장과 게임 제목(PARAM.SFO)
  • 게임 글꼴: Umdot 13(한글 14×14)과 Galmuri11(영문·숫자 반각). 그림 글자: Galmuri, Black Han Sans, Pretendard SemiBold, Noto Sans KR, 나눔명조 Bold

원문 그대로인 것

영문 로고·장식 글자, 타이틀 저작권 줄, 오프닝 영상 속 글자, 학원 이벤트 배경 그림 속 간판 글씨(예: 교문의 「美星學園高校」), 스태프롤 일부 배경 그림은 원본 그대로입니다. 14px 굵은 글꼴 특성상 에/애, 안/언/인처럼 획이 1~2화소 차이인 글자가 비슷해 보일 수 있고, 좁은 글자(1, 쉼표) 둘레 간격이 조금 고르지 않을 수 있습니다.

확인 범위

PPSSPP v1.20.4에서 확인했습니다. 미션 중 무전 음성 자막은 확인하지 못했고, 이름 입력 화면, 「ATTENTION」 안내창, 학원 모드 내 저장은 최종 빌드에서 직접 보지 못했습니다. 처음부터 끝까지 이어서 시험 플레이하지는 않았고, PSP 실기에서는 배포 빌드를 확인하지 않았습니다.

GitHub Issues ↗

원본 해시가 다르면 패처가 적용을 거부합니다. CSO·CHD는 먼저 ISO로 바꿔 주세요. 타이틀의 「데이터 설치」는 쓰지 마세요. 일본어판으로 이미 설치했다면 한글판 첫 실행 전에 메모리스틱의 설치 데이터를 지워 주세요. 일본어판 세이브는 두 판을 오가며 쓰지 말고, 한글판 세이브는 따로 보관하세요. PPSSPP에서는 텍스처 업스케일을 끄고 필터링을 「근접」으로 두세요. 글자가 잘리거나 일본어가 남은 곳, 어색한 문장을 발견하시면 장면과 화면 사진을 함께 알려 주세요.
