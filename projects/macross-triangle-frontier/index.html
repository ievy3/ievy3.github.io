작업 상세 정보한글화 범위 · 원문 유지 · 확인 범위

한글화 범위

  • 대사·학원 이벤트·미션 브리핑·메뉴·설명·스태프롤 약 48,300행
  • 실행 파일 속 문구 약 2,875행
  • 글자가 든 그림 1,123장
  • 게임 글꼴: Umdot 13(한글)과 Galmuri11(영문·숫자)로 새로 그림(한글 1,269자)

원문 그대로인 것

학원 이벤트 배경 그림 136장 속 간판 글씨(예: 美星學園高校), 타이틀 저작권 줄, 오프닝 영상 글자, 스태프롤 로고 등은 일본어 그대로입니다. 좁은 글자(숫자 1, 쉼표 등)의 간격은 일부 어색할 수 있습니다.

확인 범위

PPSSPP v1.20.4에서 화면을 확인했습니다. 미션 중 무전 자막, 이름 입력 화면, ATTENTION 창, 학원 모드 내 저장은 최종 빌드에서 직접 보지 못했고, 처음부터 끝까지 이어서 시험 플레이하지는 않았습니다. PSP 실기에서는 배포 빌드를 확인하지 않았습니다.
