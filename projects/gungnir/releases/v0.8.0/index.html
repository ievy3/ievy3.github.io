RELEASE SUMMARY

버전 개요

이벤트·맵·전투·메뉴 관련 주요 텍스트와 한글 폰트를 통합하고 정적 구조 및 ISO 생성 검증을 거쳐 처음 공개한 검수판입니다. 초반부 플레이는 확인했지만 전체 구간의 플레이 검증은 완료되지 않은 상태로 배포했습니다.

CHANGES

주요 변경 사항

  • 주요 스토리 및 게임 내 텍스트 한국어 적용
  • 이벤트·맵·전투·메뉴 관련 텍스트 통합
  • 한글 폰트 적용
  • 정적 구조 및 ISO 생성 검증 완료
  • 초반부 플레이 확인
  • Windows용 오프라인 통합 패처 배포
  • 전체 게임 플레이 검수 착수

KNOWN ISSUES

알려진 사항

이미지 현지화 진행 중 · 일부 이미지에 임시 영문 이미지 또는 롤백 과정에서 다시 섞인 일본어 이미지가 남아 있었으며, 전체 플레이 검증도 완료되지 않았습니다. 이미지 작업과 대사 교정을 추가한 v0.9.0이 이후 배포되었습니다.
