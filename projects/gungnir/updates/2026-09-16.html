완료 수치는 최신 시험 ISO의 재추출 기반 정적 검증 결과입니다. 전체 장면 진행과 저장·불러오기 등 실제 플레이 검증 완료를 의미하지 않습니다.

01 · 맵 대사 범위 확장 및 최종 통합32개 맵 · 4,580행
  • 기존 통합본에서 누락됐던 맵 대사 범위를 다시 추적했습니다.
  • 총 32개 맵의 맵 대사 4,580행을 최신 통합본에 반영했습니다.
  • 이벤트 장면 85개와 함께 최종 시험 ISO에 재통합했습니다.
02 · 보조 표시문과 공통 폰트 확장411행 추가 반영
  • 위치 설명·배너·강조문 등 보조 표시문 411행을 추가했습니다.
  • 새로 필요한 한글 글리프를 공통 폰트에 반영했습니다.
  • 전투 문구 446개를 포함해 EBOOT·폰트 영역을 다시 통합했습니다.
03 · 캐러밴 첫 맵 크래시 안정화고정 배치 방식 적용
  • 캐러밴 전투 첫 맵에서 발생하던 크래시를 조사했습니다.
  • 해당 맵을 원본 주소와 제어 데이터를 유지하는 고정 배치 방식으로 변경했습니다.
  • 이 방식의 시험본에서는 사용자가 첫 맵 크래시가 발생하지 않음을 확인했습니다.
  • 최신 통합본에서도 첫 맵은 크래시가 없었던 검증본과 동일한 구조를 유지합니다.
04 · 튜토리얼 이미지 레이아웃 확정53장 보정 · 57장 반영
  • 튜토리얼 57장 중 53장의 레이아웃을 수정했습니다.
  • 페이지 번호와 Next 표시 영역이 겹치지 않도록 배치를 보정했습니다.
  • 수정된 57장 세트를 이후 빌드의 기준선으로 확정하고 최신 ISO에 반영했습니다.
05 · 최신 시험 ISO 생성 및 정적 재검증재추출 기반 확인
  • 이벤트·맵·EBOOT·폰트·이미지를 다시 통합해 최신 시험 ISO를 생성했습니다.
  • 생성된 ISO를 다시 추출해 통합 대상이 들어갔는지 정적 검증했습니다.
  • 전체 플레이 검수는 별도 단계로 남겨 두었습니다.

정적 기준으로는 이벤트·맵·전투 문구·폰트·튜토리얼 이미지가 최신 시험 ISO에 통합됐습니다. 특히 첫 맵은 크래시가 없었던 고정 배치 구조를 유지합니다. 다만 전체 장면 진행, 한글 표시, 저장·불러오기 등은 실제 플레이 검수가 남아 있어 아직 배포 준비 완료 상태는 아닙니다.

REFERENCE NOTE

첫 맵 안정화 기준

첫 맵은 원본 주소와 제어 데이터를 유지하는 고정 배치 방식을 기준으로 합니다. 이후 수정에서도 이 구조를 우선 보존하고, 다른 맵으로 확대 적용할 경우 별도 플레이 검증을 수행합니다.

게임 원본 데이터와 패치 적용 결과물은 배포하지 않으며, OP 영상은 한글화 대상에서 제외합니다.
