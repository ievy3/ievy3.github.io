TUTORIAL

튜토리얼 57장 Pretendard 전환

  • 실제 480×272 화면 크기로 비교한 뒤 본문은 Pretendard SemiBold(600) 15px, 빨간 소제목은 Pretendard Bold(700) 20px로 확정했습니다.
  • 기존 navigation-safe 배치, 번역문, 줄바꿈, 그림 크롭, 강조색과 소제목의 -3px 세로 보정을 유지했습니다.
  • 이전 빌더에서 그대로 복사되던 4장을 포함해 57장 전체가 새 글꼴로 다시 생성되도록 빌드 경로를 수정했습니다.
  • 두 글꼴의 OS/2 굵기와 튜토리얼 사용 문자 474개의 Unicode cmap 지원을 확인했습니다.
  • 하단 게임 오버레이 영역 y=240..271, 그림 크롭, 글자 영역 밖 픽셀이 기존 navigation-safe 기준과 동일한지 검사했으며 화면 밖 글자와 새 겹침은 발견되지 않았습니다.
  • 이미지 57장, 검수 시트 5장, PNG 패키지, 글꼴·설정 해시를 포함한 검증 기록을 생성하고 최종 이미지 에셋 입력에 반영했습니다.

IMAGE UPDATE

승리 결과·준비 메뉴·챕터 이미지 최신화

  • 승리 결과 이미지 74장에 일본어 제목과 안내문을 한글화한 최신 렌더를 반영하고 영문·숫자·그래픽과 비대상 페이지는 유지했습니다.
  • 준비 메뉴 13~14페이지는 Noto 계열 재작업본, 15페이지는 한글 최신본, 16페이지는 Noto Sans KR 900 적용본을 사용했습니다. 속성 표기 火 水 地 風은 원본 한자를 유지했습니다.
  • 28개 챕터의 제목과 잔상 이미지 56장에 송명체 최신본을 반영하고 각 챕터의 비대상 page_01은 9월 20일 상태를 보존했습니다.
  • 새 패키지에 포함된 무수정 일본어 복사본은 적용 대상에서 제외해 기존 한글 에셋이 되돌아가지 않도록 했습니다.

ASSET MERGE

9월 20일 에셋에 이미지 191장 병합

기존 팔레트를 고정한 첫 시도는 구조 검사 자체는 통과했지만 튜토리얼 배경에 얼룩과 색 띠가 확인되어 사용하지 않기로 했습니다. 최종본은 튜토리얼 페이지별 팔레트를 다시 구성하는 방식으로 변경해 해당 시각 문제를 해소했습니다.

현재 판단

9월 22일 이미지 갱신분 191장은 9월 20일 에셋과 기준 ISO에 병합됐고 ISO 재추출을 포함한 정적 검증을 통과했습니다. 튜토리얼의 기존 팔레트 문제는 페이지별 팔레트 재구성으로 해소했으며, 비대상 게임 데이터와 첫 맵 고정 레이아웃은 보존했습니다. 실제 게임에서의 표시 상태와 진행 안정성은 아직 확인되지 않았습니다.
