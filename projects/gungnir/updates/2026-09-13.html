전체 플레이 검증미완료

완료율은 각 항목에 적힌 범위만 나타냅니다. 장면 추출과 단위 검사가 완료됐더라도 번역·통합·전체 플레이 검증은 계속 진행됩니다.

01 · 원본 보존형 작업 기반 확인DAR 3개 왕복 검증
  • 게임의 주요 아카이브 3개를 추출하고 수정 없이 다시 조립했을 때 전체 바이트가 원본과 일치했습니다.
  • 총 2,191개 구성원의 범위와 중복, 압축 해제 결과를 검사했습니다.
  • 원본 데이터를 보존한 채 필요한 자산만 바꾸는 작업 흐름을 확정했습니다.
02 · 대사와 폰트 표시 기반 구축한글 대사 화면 확인
  • 대사·이름표 명령과 11pt·12pt 폰트 구조를 분석했습니다.
  • 첫 한글 대사와 다음 대화로의 전환을 실제 화면에서 확인했습니다.
  • 문장부호와 3줄 대사가 말풍선에 맞게 표시되도록 처리 방식을 수정했습니다.
  • 현재 화면 확인은 초기 장면에 한정되며 전체 폰트와 전체 장면의 검증은 아닙니다.
03 · 전체 장면 추출과 장면 번역85개 지원 · 295개 검토
  • 일본어·영어판 각 85개 장면의 텍스트 경계를 읽는 추출 기반을 마련했습니다.
  • partA01 113개와 partA02 142개의 대사·이름표 검토를 마쳤습니다.
  • partA03은 461개 가운데 40개를 검토했으며 421개가 남았습니다.
  • 일본어와 영어의 항목 수가 다른 장면은 순번으로 자동 대응하지 않고 의미를 기준으로 확인합니다.
04 · 공통 문자열과 이미지 작업 착수아이템·장비 253개 1차 번역
  • 아이템·장비 관련 문자열 824개 가운데 253개를 1차 번역했습니다. 570개는 대기, 1개는 보류 상태입니다.
  • 이미지 후보 1,173장을 추출하고 22개 유형으로 분류했습니다.
  • 자동 생성 초벌은 오독과 배경 훼손 문제가 있어 승인본으로 인정하지 않았습니다. 현재 승인본은 0장입니다.
05 · 첫 장면 재삽입과 정적 검사113개 텍스트 기술 검증
  • 첫 장면의 대사 72개와 이름표 41개를 가변 길이로 다시 넣는 기술 흐름을 구축했습니다.
  • 장면 명령 844개와 주소 참조 23개를 검사했습니다.
  • 현재 파이썬 단위 검사 37개가 모두 통과했습니다.
  • 이는 기술 재삽입 검증이며, 113개 문장의 최종 번역·전체 플레이 완료를 뜻하지 않습니다.
