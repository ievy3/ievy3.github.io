FAQ 및 오류 제보지원 범위·제보 방법

원본 게임도 제공하나요?

아니요. ROM, ISO와 원본 게임 파일은 제공하지 않습니다.

다른 지역판에도 적용되나요?

첫 배포에서 지정할 원본 버전과 해시를 기준으로 지원합니다.

문제는 어디에 제보하나요?

GitHub Issues ↗에 패치 버전, 실행 환경, 발생 위치와 스크린샷을 남겨 주세요.
