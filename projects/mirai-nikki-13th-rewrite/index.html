한글화 범위

  • 번역 대상: 대사 16,706행 + 실행 파일 930행(같은 원문 1,634행은 합칠 때 채움)
  • 그림 문구 484행(그림 목록 분류 확정 후 요청 예정)
  • 글꼴: 한글 2,350자를 Pretendard 15px로 새로 그렸습니다.

그대로 둘 것

장면 제목 589행은 메모리에 복사만 되고 화면에 그려지지 않아 그대로 둡니다. 스태프롤 그림 65장은 원문을 유지하고, 화면에 나오지 않는 내부 이름 285건은 바꾸면 멈추기 때문에 그대로 둡니다. 번역이 끝나기 전에는 변경될 수 있습니다.

확인 범위

한글 대사·선택지·실행 파일 문구의 시험 표를 화면으로 확인했습니다(16장 중 통과 11장, 판단 불가 4장). 번역을 합친 빌드는 아직 만들지 않았고 PSP 실기에서는 확인하지 않았습니다.
