PPSSPP · PSP 실기

애니메이션 『미래일기』를 바탕으로 한 PSP용 어드벤처 게임입니다. 미래를 적는 「일기」를 가진 소유자들이 벌이는 생존 게임을 따라갑니다.

RECENT UPDATE

11월 23일 · v1.0.3 배포 꾸러미 완성

  • 게임 본문 20,927문장과 실행 파일 문구 1,063개, 그림 188장을 한글화했습니다. 대사 글꼴은 Pretendard, 일기 휴대폰은 Galmuri11 12px입니다.
  • 멈춤(유노 게이지 장면, 선택지 뒤)과 정보 카드·실행 파일 문구의 칸 넘침을 모두 찾아 고쳤습니다.
  • 배포 점검 16차를 통과했고 패처 시험 8가지를 마쳤습니다. 앞선 v1.0.0~v1.0.2 꾸러미는 공개하지 않았고, v1.0.3이 첫 공개판입니다.
  • 공개 게시만 남았습니다.

작업 상세 정보한글화 범위 · 알려진 문제 · 확인 범위

한글화 범위

  • 게임 본문 20,927문장, 실행 파일 문구 1,063개(말투 정본: 용어·말투 156쌍과 화자·청자 정리)
  • 그림 188장(글자를 지운 4-b·4-a 그림, 날짜 그림의 숫자 덮기 포함)과 새로 만든 4-b 그림 95장, 한글 로고(원문의 둥근 구멍 포함)
  • XMB 게임 제목 「미래일기 13번째 일기 소유자 RE:WRITE」와 저장 화면 제목·설명, 뒷면 미래일기 이름 63행, 인물 이름표, 대사 기록 화자 이름
  • 글꼴: 대사 Pretendard Regular, 일기 휴대폰 Galmuri11 12px, 메뉴 설명 그림 고운바탕 Bold, 그림 글자는 벡터 글꼴 위주(OFL)

그대로 둔 것 · 알려진 한계

저작권 표기와 출판사 로고, 스태프롤 그림 65장, 장면 제목 589행(화면에 그려지지 않음), 가게 간판과 판독할 수 없는 잔글씨 그림, 포스터 윗머리 「通り魔事件」, 화면에 나오지 않는 내부 이름(바꾸면 멈춤), 음악 일기 곡 이름 「もちぺったん」은 원문 그대로입니다. 저장 매체 없음·공간 부족 저장 안내 4행과 정보 목록 이름 칸(잠긴 「???」 항목)은 화면으로 칸 한도를 확인하지 못했습니다. 첫 저장 때 멈추는 일이 원본에서도 6번에 1번 생기는 동작이라 안내문에 적었습니다.

확인 범위

PPSSPP에서 확인했고, 제작자가 PSP 실기로 멈춤 수정판과 정보 카드 화면을 확인해 통과했습니다. 소리를 켠 자동 플레이 약 1시간에서 오류 화면이 없었고, 배포 점검 16차(주요 문제 0건)를 통과했습니다. 올 클리어 세이브로도 잠긴 항목과 엔딩 일부는 보지 못했습니다.
