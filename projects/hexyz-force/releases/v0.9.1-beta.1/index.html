RELEASE SUMMARY

버전 개요

v0.9.0에서 메뉴 설명 일부가 깨져 보이던 원인을 수정한 버전입니다. 게임의 전용 줄바꿈 이스케이프를 올바르게 적용했으며, 스토리 대사와 번역 데이터 자체는 v0.9.0과 동일합니다.

CHANGES

주요 변경 사항

  • 몬스터 도감·인물 소개 등 메뉴 설명 문자열 140건의 줄바꿈 표시 오류 수정
  • 원본 게임의 전용 줄바꿈 이스케이프 방식에 맞게 설명 문자열 기록 방식 수정
  • 대사·번역 데이터는 v0.9.0과 동일
  • PSN판·UMD판 원본 자동 판별 및 SHA-256 검증 유지
  • 전체 플레이 검수 계속 진행

KNOWN ISSUES

알려진 사항

공개 검수판 · 전체 플레이 검수가 진행 중이며, 이후 이벤트 로그의 긴 화자명 표시 문제를 추가 수정한 v0.9.2가 배포되었습니다.
