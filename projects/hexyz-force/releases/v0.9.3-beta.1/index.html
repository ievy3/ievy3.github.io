RELEASE SUMMARY

버전 개요

v0.9.2가 PPSSPP에서는 정상 동작했지만 일부 PSP 실기 환경에서 80020148 오류로 시작되지 않는다는 제보가 있어 실행 파일 구조를 일본어 원본과 같은 형태로 복원했습니다. 번역문과 화면 표시는 v0.9.2와 동일합니다.

CHANGES

주요 변경 사항

  • PSP 6.61 ARK-5 환경에서 보고된 ‘기동에 실패했습니다 (80020148)’ 오류에 대응
  • 패치된 실행 파일을 일본어 원본과 같은 구조로 복원
  • 번역문과 화면 표시는 v0.9.2와 동일
  • PSN판·UMD판 원본 자동 판별 및 SHA-256 검증 유지
  • PPSSPP에서 기동 확인
  • PSP 실기 동작은 추가 확인 중
  • 이전 한글 ISO에 덧씌우지 않고 일본어 원본 ISO에서 다시 패치해야 함

KNOWN ISSUES

알려진 사항

이벤트 로그 표시 제한 · 원본 게임 사양상 이벤트 로그는 항목당 최대 3줄까지만 표시합니다. 4줄 이상의 대사는 로그에서 뒷부분이 보이지 않지만 게임 진행에는 영향이 없습니다.
