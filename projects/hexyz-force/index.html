검증 상태
전체 플레이 및 UMD판 실행 검증 진행 중
  1. 오프라인 통합 패처 ZIP을 다운로드하고 압축을 풉니다.
  2. 압축을 푼 폴더에서 패처 EXE를 실행합니다.
  3. 직접 보유한 일본어 원본 ISO를 선택합니다.
  4. 새 ISO의 저장 위치를 지정하고 패치 적용을 누릅니다.
  5. 완료 후 생성된 한글 ISO를 실행합니다.

인터넷 연결이나 별도의 xdelta·XML 파일은 필요하지 않습니다. 사용자가 직접 보유한 지원 버전의 원본 ISO가 필요하며, EXE에 코드 서명이 없어 Windows에서 게시자 확인 경고가 표시될 수 있습니다.

남은 검증 항목공개 전 체크리스트
  • 등록되지 않은 문자열 후보 분류 및 필요한 항목 추가
  • 두 루트 전 구간 플레이 검증
  • 대화 기록창·선택지·저장·불러오기 집중 확인
  • 실제 화면의 줄바꿈·겹침·잘림 최종 QA
  • 깨끗한 원본에 배포 패치 적용 후 재검증
알려진 문제 및 오류 제보베타 주의사항·제보 방법

현재 전체 플레이 검증과 미등록 문자열 후보 판정이 진행 중입니다. 이벤트 로그는 원본 게임의 표시 사양상 항목당 최대 3줄까지만 보이며, 4줄 이상의 대사는 로그에서 뒷부분이 표시되지 않습니다. 게임 진행에는 영향이 없습니다. 그 밖의 줄바꿈·겹침·잘림이나 특정 구간 진행 문제를 발견하면 아래 채널로 알려 주세요.

원본 게임도 제공하나요?

아니요. ROM, ISO와 원본 게임 파일은 제공하지 않습니다.
