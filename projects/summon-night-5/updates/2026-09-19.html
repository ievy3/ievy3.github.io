01 · Phase 0 종료와 Gate 0 통과ISO 왕복·문자열 표시 경로
  • 복호화 EBOOT와 ISO 리빌더를 정리하고 왕복 리빌드에서 42개 파일의 MD5가 모두 일치함을 확인했습니다.
  • 제자리 치환과 더 긴 문자열 재배치 시험을 통과했습니다.
  • 미매핑 한글이 ★ 폴백으로 표시되며 크래시하지 않는 것을 화면에서 확인했습니다.
  • 별도 이름 입력 시스템이 없음을 확인해 고정 이름 번역 방식으로 진행하기로 했습니다.
02 · 시나리오 전량 추출과 재삽입 실증59,876 문자열
  • 00.DAT가 시나리오 아카이브임을 확인하고 187개 추출 파일에서 UTF-8 문자열 59,876개를 확보했습니다.
  • 압축 해제·재압축 경로를 구현하고 문자열 수정 후 ISO 리빌드까지 전체 체인을 검증했습니다.
  • 고정 길이뿐 아니라 51B→72B 가변 길이 문자열도 append + retarget 방식으로 삽입해 정상 표시를 확인했습니다.
03 · 스크립트 VM과 대사 구조 분석23,756 레코드 · 오류 0
  • VM 바이트코드를 파싱해 문자열 참조와 대사 출력 호출 구조를 확인했습니다.
  • 메시지 ID가 JP/EN 양쪽에 공통으로 존재해 정렬 앵커로 사용할 수 있음을 확인했습니다.
  • 화자 정보는 전역 ID가 아닌 씬 로컬 ID를 사용하는 것으로 확인되어 추가 매핑을 진행 중입니다.
04 · 폰트 역공학과 한글 글리프 표시16×16 4bpp · 2,350슬롯
  • 본문용 16×16 4bpp 폰트와 ASCII용 8×16 폰트 구조를 확인했습니다.
  • 한글 페이지가 비어 있어 미사용 한자 슬롯을 재활용하는 방식으로 한글 매핑을 구성했습니다.
  • 4bpp 니블 순서 오류를 수정한 뒤 NotoSansKR Medium 기반 한글 2,350슬롯을 굽고 인게임 표시를 확인했습니다.
  • 대사창 유효폭은 약 357px, 전각 기준 약 22자/줄·2줄로 측정했습니다.

  • 시범 장면 번역을 통해 루트 분기와 화자 힌트를 포함한 번역 프롬프트 구조를 검증했습니다.
