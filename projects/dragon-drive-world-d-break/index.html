한글화 범위

  • 일반 번역표 문장 5,757행과 별도로 찾은 일본어 원문 272행
  • 설명문 868행, 드래곤·기술·아이템 고정 명칭 869개, 인명 26개
  • 이름표 22개·인명 별칭 5개, 전투 중 드래곤 이름 그림 167종
  • 그림: 타이틀 로고, 시나리오 선택·저장·불러오기, 입구·배틀 아레나, 팀 편집, 로비, D대전·교환·훈련·안내·시간설정·실체화 메뉴, 휴대폰·카드·전투 명령/반응·재도전 그림
  • 이름 입력 4페이지(한글 기본 이름 포함), 스태프롤 직함
  • 글꼴: Galmuri

알려진 한계

승리·보상 화면과 엔딩은 이번 빌드로 직접 확인하지 못했습니다. 카즌R 엘레강스·센코쿠라 광속·센코쿠라 중장갑이 상대로 나오는 전투는 실제 화면으로 확인하지 못했습니다(타일 배치만 정적으로 검증). 상점·제작·훈련·안내·시간설정·실체화 화면의 실제 진입 경로는 확정하지 못했습니다. 읽지 못한 일본어 글자 31종은 문맥으로 번역했으며, 일부 고유명사는 공식 한국어 명칭이 아닌 잠정 표기입니다. 모든 분기와 모든 문자열을 직접 진행해 보지는 못했습니다.

확인 범위

mGBA 0.10.5(Windows)에서 타이틀, 시나리오 선택, 첫 장면 대사, 팀 편집, VS 화면, 아레나 전투(명령창·대사·이름·기술 연출), 게임 오버·재도전을 확인했습니다. 전투 기술 연출 중 HUD 이름이 사라지거나 깨지지 않는 것을 블레이드·화염구·쁘띠 브레스 각 100프레임 단위로 측정했고, 이름 그림 167개의 타일 배치는 충돌 없이 정적 검증했습니다. 실기·플래시 카트와 통신은 확인하지 않았습니다.
