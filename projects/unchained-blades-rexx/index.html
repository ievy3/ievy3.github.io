작업 상세 정보한글화 범위 · 알려진 문제 · 확인 범위

한글화 범위

  • 번역: 대사·메뉴 등 10,732행(묶음 72개)과 그림 문구 330문구, 실행 파일 문구 5,026행
  • 그림: 본편 436장, 직접 만든 그림 42장(구슬 35장, 신전 제목, 타이틀 로고 등), XMB 로고·배경
  • 영상: 장 제목 영상 8편(Ctitle0~7)
  • 주인공 이름 입력: 기본 이름 「팡」, 한국어 입력을 코드표로 변환
  • 글꼴: 대사 NotoSansKR 13px, 그림 글자 Gothic A1 Bold

알려진 한계(수정 예정)

로딩 로고와 일부 로딩 화면 문구(「決定」「残り　回」)가 아직 일본어로 남아 있어 한글화할 예정입니다. 상점·퀘스트 화면은 세이브로 닿지 않아 한계로 닫았고, 이름 입력 화면에서 일부 글자가 「?」로 보이는 것은 에뮬레이터 한계입니다.

확인 범위

PPSSPP에서 확인했습니다. 번역 누락 일본어는 전수 점검에서 0건이었고(남은 것은 설명 일부), 전투·스킬·메뉴·타이틀·영상 화면을 판정했습니다. 직접 시험 플레이가 진행 중이며 PSP 실기에서는 확인하지 않았습니다.
