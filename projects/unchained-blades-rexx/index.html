작업 상세 정보한글화 범위 · 알려진 문제 · 확인 범위

한글화 범위

  • 번역: 대사·메뉴 등 10,732행(묶음 72개)과 그림 문구 330문구, 실행 파일 문구 5,026행
  • 그림: 본편 436장, 직접 만든 그림 42장(구슬 35장, 신전 제목, 타이틀 로고 등), 로딩 로고, 던전 이름판 9종, XMB 로고·배경
  • 영상: 장 제목 영상 8편(Ctitle0~7), 영상 2편의 한국어 자막
  • 저장 데이터 제목·설명 한글 표시
  • 주인공 이름 입력: 기본 이름 「팡」, 한국어 입력을 코드표로 변환
  • 글꼴: 대사 NotoSansKR 13px, 그림 글자 Gothic A1 Bold

알려진 한계

상점·퀘스트 화면은 세이브로 닿지 않아 화면으로 보지 못했습니다. 설치 데이터가 없고 세이브가 있는 조합과 저장 창도 직접 보지 못했습니다. 이름 입력 화면에서 일부 글자가 「?」로 보이는 것은 에뮬레이터 한계입니다. 캠프 스킬 화면의 글자색 대비가 낮은 점은 그대로 두었습니다.

확인 범위

PPSSPP에서 전체 점검과 재점검을 통과했고, 화면 판정에서 일본어가 남은 곳은 없었습니다. PSP 실기에서는 제작자가 헥토르 「디펜스」 이름, 던전 이름판, 영상 자막, XMB의 한글 세이브 제목을 확인했습니다. 게임을 처음부터 끝까지 진행해 보지는 않았습니다.
