한글화 범위

  • 대사·이벤트 문장 8,925행, 실행 파일 안의 메뉴·설명 등 5,026행
  • 그림 490장(타이틀·로딩 로고, 메뉴·상점 그림, 구슬 그림, 던전 이름판 등), XMB 아이콘·배경
  • 영상: 장 제목(Ctitle0~7)과 movie2·movie3 자막
  • 저장 데이터 제목·설명 한글 표시
  • 주인공 기본 이름 「팡」, 이름 입력에서 L/R로 한국어 키보드 사용
  • 글꼴: 대사 NotoSansKR 13px, 그림 글자 Gothic A1 Bold 외

일부러 그대로 둔 것 · 알려진 한계

이름 입력(시스템 키보드) 창의 제목과 기본 이름은 시스템 글꼴에 한글이 없어 영문입니다. 오프닝 로고·오프닝 크레디트·엔딩 크레디트 영상, 튜토리얼 설명 그림 속 게임 화면, 설치 폴더의 그림은 원문 그대로입니다. 데이터 묶음(csbn) 13개 파일의 일본어는 게임에 넣지 않았고, 그중 409행(구슬·스킬 연결·무기 등)은 어느 화면에 쓰이는지도 확인하지 못했습니다. 캠프 스킬 화면에서 선택 줄 위 전투 전용 스킬 이름의 글자색 대비가 낮습니다. 타이틀의 INSTALL 메뉴는 누르지 마세요.

확인 범위

PPSSPP 1.20.4에서 타이틀, 새 게임, 이름 입력, 대사, 메인 메뉴·아이템·스킬·장비·상태·지도·저장 목록, 전투, 캠프 스킬 화면 등을 확인했습니다. 게임 전체를 플레이하며 확인한 것은 아닙니다. PSP 실기에서는 제작자가 XMB 저장 제목 한글, 스킬 「디펜스」 이름, 던전 이름판, 영상 자막을 확인했습니다. 설치 없음 × 세이브 있음 조합, 저장 창, 시스템 대화상자, csbn 일부 화면은 이 판으로 보지 못했습니다.
