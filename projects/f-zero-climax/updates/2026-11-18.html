1.0.0 배포 꾸러미와
화면 정리

배포 전 점검을 통과해 1.0.0 배포 꾸러미를 만들고, 배포용 화면을 새로 찍었습니다.

RELEASE
13가지패처 시험 통과
2종배포 파일(.bps·ZIP)
6장플레이 화면

RELEASE

배포

  • 배포 전 점검(덮임 점검 미처리 0, 엄격 점검 통과, 전 묶음 검수 주요 문제 0, 말투 점검 0건)을 통과했습니다. 화면으로 못 본 항목은 안내문의 「화면에서 본 적 없는 것」에 적고 진행하기로 했습니다.
  • 1.0.0 배포 꾸러미(패처 EXE에 BPS를 담은 ZIP, 사용방법, 해시 목록)를 만들었고 패처 시험 13가지를 통과했습니다. 이후 사용방법 안내문의 줄바꿈이 어긋난 것을 고쳐 ZIP과 해시만 다시 만들었고, 안내문에 .bps 파일은 이 압축 파일과 따로 배포한다는 설명을 바로잡았습니다.
  • 배포는 .bps 파일 하나와 EXE 판 ZIP 하나로 하기로 했습니다.

SCREENS

배포용 화면

  • 스토리 위주라는 지적에 따라 플레이 화면 6장을 새로 찍었습니다. 레이스 출발(뮤트 시티), 타이틀 데모 레이스 4장(한글 말풍선과 주행 화면), 머신 선택입니다.
  • 메뉴 화면 두 장(모드 선택·그랑프리)은 창 효과가 그려지지 않아 찌꺼기가 보여 뺐습니다.
