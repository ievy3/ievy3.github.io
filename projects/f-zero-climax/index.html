mGBA

2004년 닌텐도가 일본에서만 발매한 GBA용 근미래 SF 레이싱 게임입니다. 스토리 모드로 애니메이션 『F-ZERO 팔콘 전설』의 이야기를 따라가며, GP·서바이벌·타임 어택, 코스 에디터와 통신 대전도 있습니다.

RECENT UPDATE

11월 18일 · 1.0.0 배포 꾸러미 완성

  • 스토리 대사·메뉴 등 2,108행을 한글화하고, 그림 102장(타이틀 부제, 옵션·에디터 화면, 선수 이름, 해금·통신 안내 등)을 넣었습니다.
  • 데모 화면 말풍선 31개와 주행 안내 자막 11줄을 한글로 바꿨습니다.
  • 프로필 설명 76개가 끝까지 내려가도록 스크롤 한도를 고치고, 스토리 줄 폭과 글자 찌꺼기 문제를 정리했습니다.
  • 1.0.0 배포 꾸러미(패처 EXE·BPS 파일)를 만들었고, 패처 시험 13가지를 통과했습니다. 공개 게시만 남았습니다.

작업 상세 정보한글화 범위 · 알려진 문제 · 확인 범위

한글화 범위

  • 스토리·모드 자막·메뉴 등 번역 2,108행(17묶음)
  • 그림 102장: 타이틀 부제, 옵션 미리보기, 코스 에디터 단추·안내, 코스 불러오기, GP 결과 선수 이름 38줄, EDIT 미리보기, 해금 안내·통신 안내 그림, 멀티부트 안 통신 글자 등
  • 데모 화면 말풍선 31개와 주행 안내 자막 11줄(강조색·십자키 아이콘 유지)
  • 글꼴: 한글 2,350자(KS X 1001)를 Galmuri11로 새로 그렸습니다.

알려진 한계

스토리 제목 줄이 겹쳐 보이는 것은 원본도 같습니다. 엔딩·크레딧, 통신 대전 안내, 해금 안내 띠, 저장 안내, 「고스트 있음」, 모드 자막 일부, 조작 설정 TYPE2~4는 화면으로 직접 보지 못했고, 제보가 오면 고칩니다. 그랑프리·엔트리 만들 때는 저장 안내 없이 저장됩니다.

확인 범위

mGBA에서 확인했습니다. 스토리 본편, 프로필 설명(76개를 끝까지 내려가며 스크롤 한도 확인), 코스 에디터, 그랑프리 한 판 완주와 결과 화면, 데모 말풍선을 화면으로 봤고, 완료 세이브로 서바이벌·타임 어택·코스 불러오기·통신 메뉴 표본에서 일본어가 남지 않은 것을 확인했습니다. 패처 시험 13가지를 통과했고 GBA 실기에서는 확인하지 않았습니다.
