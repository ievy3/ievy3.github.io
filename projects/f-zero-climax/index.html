mGBA

2004년 닌텐도가 일본에서만 발매한 GBA용 근미래 SF 레이싱 게임입니다. 스토리 모드로 애니메이션 『F-ZERO 팔콘 전설』의 이야기를 따라가며, GP·서바이벌·타임 어택, 코스 에디터와 통신 대전도 있습니다.

RECENT UPDATE

11월 17일 · 시험 플레이 반영

  • 스토리 대사·메뉴 등 2,108행을 한글화하고, 그림 57장과 뒤에 찾은 그림(옵션 미리보기, 에디터 단추, 선수 이름 등)을 모두 넣었습니다.
  • 데모 화면 말풍선 31개를 한글로 바꿨습니다.
  • 직접 시험 플레이에서 나온 GP 결과 선수 이름과 EDIT 미리보기의 일본어를 한글로 바꿨습니다.
  • 완료 세이브로 서바이벌·타임 어택·코스 불러오기·통신 메뉴를 확인했고 일본어는 남지 않았습니다. 공개 일정은 정해지지 않았습니다.

작업 상세 정보한글화 범위 · 알려진 문제 · 확인 범위

한글화 범위

  • 스토리·모드 자막·메뉴 등 번역 2,108행(17묶음)
  • 그림: 처음 목록 57장과 옵션 미리보기, 코스 에디터 단추·안내, 코스 불러오기, 선수 이름, EDIT 미리보기 등 추가 그림
  • 데모 화면 말풍선 31개(강조색·십자키 아이콘 유지)
  • 글꼴: 한글 2,350자(KS X 1001)를 Galmuri11로 새로 그렸습니다.

알려진 한계

스토리 제목 줄이 겹쳐 보이는 것은 원본도 같습니다. 좁은 띄어쓰기(6px)가 걸리는 다른 글, 「고스트 있음」, 통신 대전 메뉴 일부, 엔딩·크레딧은 아직 화면으로 확인하지 못했습니다.

확인 범위

mGBA에서 확인했습니다. 스토리 본편 화면, 모드 자막, 프로필 설명, 조작 설정, 코스 에디터, GP 결과 순위표, 데모 말풍선 31개 중 29개를 화면으로 봤고, 완료 세이브로 서바이벌·타임 어택·코스 불러오기·통신 메뉴 표본에서 일본어가 남지 않은 것을 확인했습니다. 직접 시험 플레이가 진행 중이며 GBA 실기에서는 확인하지 않았습니다.
