작업 상세 정보한글화 범위 · 원문 유지 · 확인 범위

한글화 범위

  • 대사·메뉴·설명 문구 약 17,000줄
  • 실행 파일 속 화면 문구 약 280곳
  • 글자가 든 그림 424장: 타이틀 로고 부제, 간판, 튜토리얼, 승패 조건, 퀘스트 카드 등
  • 영상 3개: 시작 영상의 로고 부제, 엔딩 자막 6줄
  • 게임 글꼴: 얇은둥근모(굵게)

원문 그대로인 것

엔딩 제작진 롤(이름·곡명·주제가 표기), 노래 효과 그림의 Up!·Down!, 메뉴 머리의 영어 장식 글자(Quest Menu 등), PSP 시스템 화면에 보이는 세이브·설치 데이터 제목과 설명, 영문과 뭉쳐 지울 수 없었던 스탬프 그림 3장의 받침 글자는 원본 그대로입니다. 비밀번호 입력기 제목은 한글이 나오지 않는 글꼴이라 영어(Password)로 바꿨습니다.

확인 범위

PPSSPP v1.20.4와 PSP 실기에서 확인했습니다. 처음부터 끝까지 이어서 플레이해 확인하지는 않았고, 후반 장의 대사 대부분, 동료 지시 메뉴, 노래 효과 그림 일부, 부대명 입력 화면, DLC 자체의 글은 화면에서 보지 못했습니다. 전투 HUD처럼 글자를 줄여 그리는 곳은 뭉쳐 보일 수 있습니다.

AI 사용

번역 일부(실행 파일 문구)와 검수, 그림 작업에 AI를 썼습니다. 어색한 문장이나 오역을 발견하시면 알려 주세요.

한글판은 전용 설치 폴더(PSP/SAVEDATA/NPJH50717KO09)를 씁니다. 일본어판으로 설치해 두셨다면 처음 켤 때 「설치 데이터가 없습니다」 창이 뜨고 디스크에서 읽어 이어집니다. 설치해 쓰려면 한글판 타이틀에서 Install을 다시 해 주세요(약 780MB 필요). 일본어판 세이브는 그대로 쓸 수 있습니다. PPSSPP에서는 텍스처 업스케일을 끄고 필터링을 「근접」으로 두세요.
