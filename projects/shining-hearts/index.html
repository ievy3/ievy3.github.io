한글화 범위

  • 대사·메뉴·아이템 등 문자열 19,618행
  • 글자가 든 그림 137장: 전투·퀘스트 연출 글자, 빵 굽기 표, 타이틀 부제 「행복의빵☆」 등
  • 프롤로그 영상의 흐르는 글과 자막(음성은 원본 그대로)
  • PSP 메인 화면(XMB): 게임 제목 「샤이닝 하츠」, 원본에 없던 배경 그림과 배경음(오프닝 곡 앞부분)
  • 게임 글꼴: Umdot 13, Galmuri11

확인 범위

PPSSPP v1.20.4에서 새 게임부터 약 1시간 진행했고, 중반 저장(레벨 44)으로 메뉴 전반, 전투, 상점, 빵 굽기의 레시피·악보 화면 등을 봤습니다. 실제 PSP-1000에서 실행과 XMB 배경·배경음을 확인했습니다. 빵을 굽는 연주 화면, 낚시, 다른 지역, 게임 중후반 이벤트와 엔딩은 번역은 들어 있지만 화면으로 보지 못했습니다.

알려진 제한

오프닝 영상 안 로고의 일본어 부제와 엔딩 스태프 크레딧 그림(실명)은 원문 그대로 두었습니다. 상태 창 능력치 칸은 줄 간격이 좁아 받침이 아랫줄에 약간 닿을 수 있습니다. 저장 대화 상자는 PSP 본체 글꼴로 그려서 기종이나 본체 설정에 따라 다르게 보일 수 있습니다.

GitHub Issues ↗

일본판 저장을 그대로 불러올 수 있지만, 불러오기 목록의 설명은 다시 저장하기 전까지 일본어로 나옵니다. 주인공의 기본 인사 문구는 새 게임을 시작할 때 저장에 들어가므로, 일본판에서 시작한 저장에서는 인사가 일본어로 나옵니다. 패치판은 설치 데이터를 쓰지 않고 언제나 UMD(ISO)에서 읽어서 일본판 설치 데이터를 지우지 않아도 됩니다. CSO·CHD는 ISO로 바꾼 뒤 적용하세요. PPSSPP에서는 텍스처 업스케일을 끄고 필터링을 「근접」으로 두세요.
