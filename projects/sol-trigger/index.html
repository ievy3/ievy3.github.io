PROJECT POLICY

일본판 기준으로 시작

초기 기술 분석은 일본판 PSP 버전(ULJM-06093)을 기준으로 진행합니다. 번역·표기 원칙과 지원 범위는 실제 추출 데이터가 확보된 뒤 확정합니다.

현재 표시된 항목은 프로젝트 시작 시점의 계획이며 완료 수치가 아닙니다.

지원 원본 및 배포 방식첫 공개 전

현재 조사 기준은 일본판 PSP 버전(ULJM-06093)입니다. 실제 지원 원본과 패치 형식은 구조 분석과 빌드 검증 후 확정합니다.

배포 시에도 사용자가 직접 보유한 지원 버전의 원본 게임 데이터가 필요하며, ROM·ISO나 패치 적용이 완료된 게임 이미지는 제공하지 않습니다.
