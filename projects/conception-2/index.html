RECENT UPDATE

11월 17일 · 일본어판 11차 빌드

  • 일본어판 기준 번역 180묶음(26,934행)과 실행 파일 문구 6,398행을 반영했습니다.
  • 일본어판 그림 59장을 한글화했고, 첫 빌드 점검(감사)을 통과했습니다.
  • 일본어판에 영어로 적힌 표기(ZERO 부대·OK·OB·TPO 등)를 한글판에서도 영어로 두는 정리를 마무리하는 중입니다.
  • 직접 시험 플레이와 공개 점검이 남아 있습니다. 공개 일정은 정해지지 않았습니다.

작업 상세 정보한글화 범위 · 알려진 문제 · 확인 범위

한글화 범위

  • 대사·메뉴 등 번역 26,934행(180묶음, 일본어판 기준)
  • 실행 파일 안 문구 6,398행
  • 그림: 영어판 기준으로 준비한 그림 485장 중 승인된 그림 갤러리를 일본어판 기준으로 다시 맞추는 중이며, 일본어판 그림 59장을 한글화
  • 글꼴: 대사 Noto Sans KR, 그림 글꼴 11종(SIL OFL)

그대로 두거나 알려진 것

일본어판에 영어로 적힌 표기(예: ZERO 부대, OK, OB, TPO)는 원본대로 영어로 둡니다. 스킬 화면이 멈추는 현상은 원본도 같습니다. 일부 그림의 글자 스타일 어긋남은 다시 그려 봤으나 글자가 좁고 작아져 그대로 두기로 했습니다.

확인 범위

Vita3K에서 화면을 판정했고, 일본어판 11차 빌드는 첫 빌드 점검(주요 문제 0건)을 통과했습니다. 직접 시험 플레이가 남아 있고 PS Vita 실기에서는 확인하지 않았습니다.
