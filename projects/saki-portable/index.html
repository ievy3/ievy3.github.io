v0.9.5는 첫 공개 프리릴리즈입니다. 자동 화면 확인과 PSP-1000 실기 구동 확인은 마쳤지만, 전체 게임을 처음부터 끝까지 사람이 플레이하며 검수한 안정판은 아닙니다.

일본판 원문을 기준으로 번역하며, 국내 정발 만화 표기를 우선합니다. 마작 용어는 국내 리치마작 통용 표기를 사용하고 캐릭터별 말투·호칭을 통일합니다. 실제 대사창 폭과 3줄 표시 한도를 기준으로 문장을 다듬습니다.

추가 확인 항목프리릴리즈 후속 검수
  • 작은 순위 결과 화면과 의상 관련 표시 추가 확인
  • 이름 입력 취소 경로와 통신 알림·경고 띠 화면 추가 확인
  • PSP 실기와 PPSSPP 사이의 본문 글꼴 폭·모양 차이 대조
  • 완결까지 검수한 뒤 v1.0 안정판 승격 여부 결정
