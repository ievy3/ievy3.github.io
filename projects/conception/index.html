  • 글꼴: 대사·메뉴 Galmuri, 일부 그림 글자 Noto Sans KR·Pretendard

원문 그대로인 것

영상(오프닝, s1~s4)은 원본 그대로입니다. 자막을 넣은 판은 PPSSPP에서 멈춰 뺐습니다. 시작할 때 나오는 SPIKE CHUNSOFT 로고, 옥상 대사 중 휴대폰 메일 화면, 이름 입력 가나표, XMB 제목과 아이콘 그림은 일본어·원본 그대로입니다. 튜토리얼 그림 일부(13장)에는 캡처 화면이나 모형 속 일본어가 남아 있고, 58장은 사용자가 만든 그림을 그대로 실어 모형 화면 일본어·작은 글자 가독성·잔획이 남아 있을 수 있습니다. 긴 문구는 표시 글자 수 한도에서 잘릴 수 있습니다.

확인 범위

PPSSPP(Windows)에서 타이틀·메뉴·튜토리얼·상점·장비·저장/불러오기·새 게임 첫 장면을 확인했습니다. 전투 전체, 업적 해제 창, 대부분의 이벤트 대사, 옛 세이브 이어하기는 제대로 보지 못했습니다. PSP-1000 실기에서는 실행되는 것까지만 확인했습니다.

AI 사용

번역 검수 등에 AI를 썼습니다. 검수에서 보류한 세부 표현(말투·쉼표 등)이 일부 남아 있고, 어색한 번역이 있을 수 있습니다.

GitHub Issues ↗

이미 일본어판으로 INSTALL 한 적이 있다면, 패치된 ISO를 쓰기 전에 메모리 스틱의 PSP/SAVEDATA/NPJH50583DAT 폴더를 지워 주세요. 안 지우면 설치본이 일본어로 남을 수 있습니다. 일본어판 세이브도 불러올 수 있지만 저장된 이름(주인공 이름 등)은 일본어로 보이고, 새 게임으로 시작한 세이브는 한글로 나옵니다. 중요한 세이브는 복사해 두세요. CSO·CHD는 먼저 ISO로 바꿔 주세요. PPSSPP에서는 텍스처 업스케일(xBRZ 등)을 끄고 필터링을 「근접」으로 두세요. 글자가 잘리거나 일본어가 남은 곳, 어색한 문장을 발견하시면 장면과 화면 사진을 함께 알려 주세요.
